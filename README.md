# GuideFlow Web

Public deployment layer for GuideFlow.

- The source-of-truth project remains in the private `GuideFlow` repository.
- This repository hosts the browser-facing deployment layer only.
- The browser application supports encrypted LIVE/Snapshot course access, Arabic/French lessons, Admin Studio and purchase agreements.
- Student presentation and validation: [Student Experience](docs/student-experience.md).
- Application change history: [Implementation log](docs/PROJECT-LOG.md).

> Do not commit passwords, OTP codes, identity documents, proxy credentials, API keys, or other secrets to this repository.
